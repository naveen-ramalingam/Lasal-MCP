# Changelog for sig-control-datapoint-text

## [02.00.003] - 2026-01-16
by _Elisa Bauer_ of _SIGMATEK GmbH & Co KG_

### Changed
- Removed the datapoints as options for CSS properties, as it isn't supported.

## [02.00.002] - 2025-11-07
by _Felix Jütte_ of _SIGMATEK GmbH & Co KG_

### Changed
- Removed the valueSourceType datapointScheme of the text property, since text values cannot be selected in this scheme.
- Replaced the preview icon with a higher-quality, non-pixelated version

## [02.00.001] - 2024-08-29
by _Mario Schmid_ of _SIGMATEK GmbH & Co KG_

### Changed
- Changed the valueSourceType of the text property to datapointObject to be able to select datapoint objects to display their texts too.

## [02.00.000] - 2024-01-31
by _Stefanie Hager_ of _SIGMATEK GmbH & Co KG_

### Changed
- Replaced JavaScript with TypeScript.

## [01.01.000] - 2023-06-12
by _Marcus Fiala_ and _Andreas Ramböck_ of _SIGMATEK GmbH & Co KG_

### Added
- Added LVD properties view tab assignment for all properties.

### Changed
- The border radius and width in group button styling and general styling can now also be set as shorthand property.
- Preview text is now also shown in the designer, if no text is set.
- Updated property descriptions.
- Removed property dragged opacity.
- Renamed property-group "Design time settings" to "Preview settings".

## [01.00.001] - 2023-01-02
by _Mario Schmid_ of _SIGMATEK GmbH & Co KG_

### Changed
- Changed displaying of preview text so it is only shown in default styling again.
