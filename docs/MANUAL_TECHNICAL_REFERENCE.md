# SIGMATEK LASAL Technical Reference (Extracted from Training Manuals & CHM Documentation)

Every architectural and conversion rule in **LASAL HMI Converter** is traced directly to the official SIGMATEK training manuals (`C:\SigmaControl\01_Manuals`), installed `.chm` documentation (`LASAL_SCREEN_EN.chm`, `VISUDesigner_EN.chm`, `VISURuntime_EN.chm`, `LASAL_CLASS_2_EN.chm`), or verified local software behavior.

---

## 1. LASAL SCREEN Project Architecture (`04 LASAL SCREEN Basics`, Ch. 1–6)

### 1.1 Project Files & Directory Layout
- **Root Project File (`.lpr`)**: INI/text header defining the LASAL SCREEN project (`[LSE Project File]`, `VERSION = 60`). Reference: `04 LASAL SCREEN Basics`, Ch. 1, pp. 8–10, 28.
- **`Project\*.lpg`**: Project settings binary (`LSE.lpg`), storing project resolution (e.g., `800x480`, `800x600`, `1024x768`, `1280x800`), global screen assignment (`GlobalScreen`), start screen (`StartScreen`), station definitions (`Station 0..255`), color palette, font table, units, schemes, function blocks (`_INTER_NEU`), alarms, and setup flags.
- **`Screen\*.lsn`**: Screen definition files (MFC `CArchive` binary streams containing Objective Views `CODDiagramModel` / `CODComponent` hierarchies + LSE data bindings). Reference: `04 LASAL SCREEN Basics`, Ch. 2, pp. 4–12.
- **`Window\*.lwn`**: Popup/dialog window definition files (`CODDiagramModel` streams + LSE bindings). Reference: `04 LASAL SCREEN Basics`, Ch. 2, pp. 10–12.
- **`Object\*.lse`**: Reusable grouped objects / composite templates (`_OBJECT`) placed onto screens or carousels, supporting server overloading (`Overload`). Reference: `04 LASAL SCREEN Basics`, Ch. 2, pp. 24–27; `05 LASAL SCREEN Advanced`, Ch. 6B, pp. 14–18.
- **`Image\*.bmp`, `*.jpg`, `*.png`**: Bitmaps and graphics imported into the LSE Image Pool (`CTRL+ALT+B`). BMP images use an explicit per-image transparent RGB key color (defaulting to Magic Pink `R=255, G=0, B=255` / `#FF00FF` or bottom-left corner pixel). Reference: `04 LASAL SCREEN Basics`, Ch. 2, pp. 13–15; `LASAL_SCREEN_EN.chm` (`lse_place-image.htm`).
- **`Runtime\*.MPC`**: Compiled binary tables generated by LSE (`Project -> Compile` or `IProject.Compile()`) and loaded by the PLC/HMI `_LSE` runtime kernel (`Stations\Terminal\HMI\Source\cppcode\T_init.cpp`, `T_prj.cpp`, `T_file.cpp`, `T_picsub.cpp`):
  - `LSE.MPC`: Project header, screen/window/global-screen directory table (`_PRJ_ENTRY`), start screen number, and compiler version (`compilerversion = 60`).
  - `GS0000.MPC`: Global Screen (`_PICTURE`) containing persistent navigation bars, status headers, and background elements.
  - `LCxxxx.MPC`: Compiled Screens (`xxxx` = 4-digit hex screen number, e.g., `LC0000.MPC` = Screen 0, `LC000A.MPC` = Screen 10).
  - `LWxxxx.MPC`: Compiled Windows (`xxxx` = 4-digit hex window number).
  - `LS0000.MPC`: Language definitions & metadata.
  - `LS0001.MPC`: Server / Variable symbol table (`_VARLIST` — hierarchy encoded via parent tokens, station number, variable type, refresh time, limits, units, schemes, CRC32 ID).
  - `LS0002.MPC`: Reusable Object templates (`_OBJECT` / `OBJLST` — subpictures with relative bounding boxes and overloaded server slots).
  - `LS0003.MPC`: Image pool table (`_BMPLIST`).
  - `LS0004.MPC`: Color palette (`16-bit RGB565` + high-byte animation/gradient attribute).
  - `LS0005.MPC`: Font definitions & Font Scheme table (`FONTSCHEME`).
  - `LS0006.MPC`: Sequence / Setup configuration.
  - `LS0007.MPC`: Image Schemes (`IMAGESCHEME`), Server Schemes (`SERVERSCHEME`), Object Schemes (`OBJECTSCHEME`), Color Schemes (`COLORSCHEME`), State Schemes (`STATESCHEME`).
  - `LS0008.MPC`: Text Schemes (`TEXTSCHEME`).
  - `LS0009.MPC`: Function Blocks (`_INTER_NEU` bytecode programs).
  - `LS0010.MPC`: Alarm configurations (`_ALARM`).
  - `LS0011.MPC`: Formula / Unit table (`_UNIT` & conversion formulas `0..255`) and Unit Schemes (`UNITSCHEME`).
  - `LS0012.MPC`: Popup Menus (`_MENULIST`).
  - `LS0015.MPC`+: Language Text Lists (`TextPuffer` UTF-16LE / ASCII string tables per language and text list ID).

## 2. LASAL SCREEN Graphic Elements, Controls & Properties (`04 LASAL SCREEN Basics`, Ch. 2)

Every `_PICTURE` (`LC*.MPC`, `LW*.MPC`, `GS0000.MPC`) or `_OBJECT` (`LS0002.MPC`) contains a `_PICTUREMASK` with strongly typed arrays of visual and interactive elements (`T_types.h`, `T_picsub.cpp`):

1. **Primitives**:
   - **Rectangles (`memrectangle` / `_RECTANGLE`)**: Bounding box (`_ROOM xy1, xy2`), fill/back color, frame color, frame style (`_DEFFRAME`, 3D raised/sunken, flat, invisible), attribute flags (`T_SOLID`, `T_COPY`, `T_INVRS`).
   - **Lines & Polygons (`mempolygon` / `_POLYGON`)**: Array of `(x, y)` vertices, pen color, line thickness/style.
   - **Circles / Ellipses (`memcircle` / `_CIRCLE`)**: Bounding box (`_ROOM`), start/arc angles, pen/fill colors, frame type.
   - **Static Images (`mempict` / `_PICTEXT`)**: Bounding box (`_ROOM`), bitmap index (`_BMPLIST`), zoom/stretch flags.
   - **Static Texts (`memattrib` / `_PICTEXT` / `colortxt`)**: Bounding box (`_ROOM`), text reference (`_ANYPARA` -> TextList + Entry index + TextScheme), font scheme index, alignment (`T_LEFTBOUND`, `T_CENTERBOUND`, `T_RIGHTBOUND`, `T_UPBOUND`, `T_MIDBOUND`, `T_DOWNBOUND`), foreground/background/frame colors.
2. **Dynamic & Interactive Elements**:
   - **Buttons (`membutton` / `_BUTTON`)** (`04 LASAL SCREEN Basics`, Ch. 2, pp. 16–21):
     - **Action / Trigger Types**:
       - Momentary / Push (`Tip` / `Momentary`): Writes `set_val` on press, `reset_val` on release to bound `varlabel`.
       - Toggle (`Switch` / `Latch`): Toggles bound server between `reset_val` (0) and `set_val` (1).
       - Radio (`Radio`): Writes constant value `set_val` to bound server on press.
       - Screen / Window Navigation (`gotoscreen` / `act_momentary` / `enter_plus`): Executes `CMD_NEWPICTURE`, `CMD_NEWWINDOW`, `CMD_RETURN`, `CMD_CLOSE`, `CMD_NEWLANGUAGE`, or triggers FunctionBlock (`sub_links` / `sub_rechts` -> `_INTER_NEU` index).
     - **Visual Properties**: Released/Pressed colors (`col`, `coltxt`), Released/Pressed bitmaps (`buttonimages`), Released/Pressed text (`text`, `text1`), Frame type (`frametype`), Hotkey scan code (`key`), Access level (`access`), Disabling server (`disable` `_VARLABEL`).
   - **Inputs & Outputs (`meminput` / `_INPUT` & `memoutput` / `_IO`)** (`04 LASAL SCREEN Basics`, Ch. 2, pp. 22–35):
     - **Subtypes (`_IOTYPE` in `T_types.h`)**:
       - `AS_NUMERIC` (0): Numeric display or editable numeric input (`Min`/`Max` limits, decimal places / format, unit scheme).
       - `AS_ASCII` (1): String display or editable string input (`String` / `StringRAM` server).
       - `AS_CHKBOX` (2): Checkbox control (`0` / `1`).
       - `AS_RADIO` (3): Radio indicator/selector.
       - `AS_BAR` (4): Level indicator bar (`membar` / `_IO`: horizontal or vertical orientation, origin/zero-point offset, min/max range, fill/background color).
       - `AS_TBO` (5): Embedded Object (`_OBJECT` reference).
       - `AS_DATE` (6): Date display/input (`YYYY-MM-DD`, `DD.MM.YYYY`, etc.).
       - `AS_TIME` (7): Time display/input (`HH:MM:SS`, `HH:MM`).
       - `AS_ENUMERATION` (8): Text list / dropdown enumeration bound to a server value.
       - `AS_THEURGE` (9): User Defined Component (`UDC` — `_THEURGE` structure containing custom arrays of servers `memvarlabel`, texts `memanypara`, images `memimage`, colors `memcolor`, fonts `memfont`, schemes `memdyncol`, and function blocks `memlsefun`). Reference: `05 LASAL SCREEN Advanced`, Ch. 5, pp. 4–21.
       - `AS_MENU` (10): Popup menu selector (`LS0012.MPC`).
   - **Motion / Dynamic Position Elements (`memmotion` / `_MOTION`)** (`04 LASAL SCREEN Basics`, Ch. 2, pp. 36–38):
     - Animates an image or object along an X/Y trajectory driven by X and Y server variables (`varx`, `vary`).
   - **Placed Sub-Objects (`memobject` / `_OBJECT` & `mempicmemo`)**:
     - Places an `Object\*.lse` (`LS0002.MPC`) at `(xy.x, xy.y)` with optional server overloading (`loader` `_VARLABEL` replacing the template's base station/object server with a specific instance such as `Pump1` or `Pump2`).
   - **Custom Kernel Controls (`_MyIO`, `_ScrollArea2`, `_Carousel`, `_AlarmDisplay`, `_Graph`)** (`05 LASAL SCREEN Advanced`, Ch. 3, 4, 6):
     - Placed in LSE with `Virtual Objectname` (`virtname`) linking the visual bounding box (`_ROOM`) to a LASAL CLASS 2 companion object (`MyColorBar1`, `MyScrollList1`, `MyCarousel1`, `AlarmDisplay1`, etc.).

## 3. Datapoints, Servers & Schemes (`04 LASAL SCREEN Basics`, Ch. 2, pp. 28–47)

### 3.1 Server Configuration (`LS0001.MPC` & `MaeExp.txt`)
- Every server in LSE belongs to a hierarchical symbol tree (`ObjectName.SubObject.ServerName`) on a specific **Station Number (`0..255`)**.
- **Variable Types (`_VARTYPE`)**:
  - `BINARY` (`DINT`, `UDINT`, `INT`, `UINT`, `SINT`, `USINT`, `BOOL`, `REAL` IEEE-754 float)
  - `STRING` (`_ASCII` / `_UNI` character arrays via `String` / `StringRAM`)
  - `TIME_LSE` / `DATE_LSE` (packed LASAL date/time bitfields)
  - `BIT` (bit-indexed access within a `BDINT` / `BINT` server)
  - `MERKER` / `OBJECT` (structural parent node in symbol tree)
- **Server Attributes**:
  - `RefreshTime` (cyclic polling interval in ms)
  - `WriteProtected` (read-only vs. read/write)
  - `AccessLevel` (`0..31` operator authorization level; `04 LASAL SCREEN Basics`, Ch. 6)
  - `LowLimit` / `HighLimit` (constant `_VARLABEL` or dynamic server `_VARLABEL`)
  - `Unit` / `UnitScheme` (physical engineering unit and conversion formula `0..255`)

### 3.2 Schemes (`04 LASAL SCREEN Basics`, Ch. 2, pp. 39–45)
Every LASAL SCREEN scheme evaluates an array of rows `(ComparisonOperator, ThresholdOperand, ResultValue)` against an input server value:
- **Operators (`_SCHEMETYPE`)**: `=` (`0`), `>` (`1`), `<` (`2`), `>=` (`3`), `<=` (`4`), `<>` (`5`), `ANY/Default` (`6`).
- **Scheme Types**:
  1. **Image Scheme (`IMAGESCHEME`)**: Maps value ranges to images in `Image\`.
  2. **Text Scheme (`TEXTSCHEME`)**: Maps value ranges to text entries in a Text List.
  3. **Color Scheme (`COLORSCHEME`)**: Maps value ranges to foreground/background color pairs.
  4. **Unit Scheme (`UNITSCHEME`)**: Switches engineering units and scaling formulas dynamically (e.g., Metric `°C`/`bar`/`m` vs. Imperial `°F`/`psi`/`ft`).
  5. **Font Scheme (`FONTSCHEME`)**: Switches font family/size per active language.
  6. **Server Scheme (`SERVERSCHEME`)**: Multiplexes which underlying PLC server is displayed/edited based on an index server (`4_PumpControlSchemeSolution`).
  7. **Object Scheme (`OBJECTSCHEME`)**: Dynamically swaps which LSE `.lse` Object is rendered based on a selector server.

## 4. Function Blocks (`_INTER_NEU`) & Event Logic (`04 LASAL SCREEN Basics`, Ch. 2, pp. 46–48)

LASAL SCREEN Function Blocks (`LS0009.MPC`) are sequential instruction blocks triggered by button press (`sub_links`), button release (`sub_rechts`), screen open/close, or value changes. Supported operations (`T_types.h` `_LSEFUN` opcodes):
- `LseMirr` (`F_MIRROR`): Copies Input 1 to Output 1 (`Out1 := In1`).
- `Add` (`F_ADD`), `Sub` (`F_SUB`), `Mul` (`F_MUL`), `Div` (`F_DIV`), `Mod` (`F_MOD`): Arithmetic operations (`Out1 := In1 op In2`).
- `Equal` (`F_EQ`), `NotEqual` (`F_NEQ`), `Greater` (`F_GT`), `GreaterEqual` (`F_GE`), `Less` (`F_LT`), `LessEqual` (`F_LE`): Relational comparisons outputting `0` or `1`.
- `And` (`F_AND`), `Or` (`F_OR`), `Xor` (`F_XOR`), `Not` (`F_NOT`): Bitwise/boolean logic.
- `Switch` (`F_SWITCH`): Conditional branch/selector (`if In1 then Out := In2 else Out := In3`).
- `Call` / Command triggers: `CMD_NEWPICTURE`, `CMD_NEWWINDOW`, `CMD_CLOSE`, `CMD_RETURN`, `CMD_NEWLANGUAGE`.

In **LASAL HMI Converter**, every LSE Function Block is migrated into both a native VISUDesigner `Functionblocks\<Name>.json` + `.js` block and a callable method in `CodeModules\MigratedLogic.js`.

## 5. Alarm Management (`04 LASAL SCREEN Basics`, Ch. 3, pp. 1–13; `01 LASAL CLASS Basics`, Ch. 16)

- In LASAL CLASS 2, each alarm uses an `_AlarmX0Para` (or `_AlarmX1Para`..`_AlarmX3Para`) instance connected to a central `_AlarmXBuffer` server.
- In LASAL SCREEN (`LS0010.MPC`), each alarm entry defines:
  - `AlarmNo` (unique alarm ID matching `_AlarmX0Para.Config`)
  - `Group` / Category
  - `Text` (linked to the `AlarmText` text list, supporting embedded parameter placeholders)
  - `Parameter` server links (`Para0..Para3`)
  - Active / Passive / Acknowledged colors
- In **LASAL VISUDesigner**, alarms are generated via `lvd.AddAlarms` (`Alarms\Alarms.json`) with `AlarmSeverity` (`Error`, `Warning`, `Information`), `ConfirmationPolicy`, datapoint condition binding, and localized text references, and rendered via `sigmatek.alarm.table`.

## 6. Language Management & Text Lists (`04 LASAL SCREEN Basics`, Ch. 4, pp. 1–25)

- Text Lists in LSE (`TextPuffer`) hold localized strings indexed by `(TextListName, EntryIndex, LanguageLCID)`.
- Standard project text lists include `ProjectText`, `AlarmText`, `TitleText`, `MenueText`, and user-defined lists.
- Exporting via `IProject2.ExportLanguagesToXML()`, `ExportTextListsToXML()`, `AddContainerInfo(true)`, and `ExportToXML(path, true)` yields complete UTF-8 XML containing every language (`Code` LCID, `Name`, `Flag` bitmap), every text list, every translation string, and `<ContainerInfo>` dimensions.
- In **LASAL VISUDesigner**, languages are registered in `Localization\Languages.json` (BCP-47 tags such as `de-DE`, `en-US`, `fr-FR`, `es-ES`, `it-IT`, `zh-CN`), text lists in `Textlists\<ListName>.json`, and synchronized via `lvd.AddLanguages`, `lvd.AddTextLists`, `lvd.AddTexts`, and `lvd.ValidateAndSynchronizeTextLists`.
