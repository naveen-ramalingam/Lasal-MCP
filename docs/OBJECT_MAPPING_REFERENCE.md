## 3. Coordinate & Layout Scaling System

`LASAL.HMI.Converter.Mapping.LayoutScaler` supports two user-selectable modes:
1. **1:1 Native Resolution Mode (Default)**:
   - Preserves the exact pixel dimensions of the source LASAL SCREEN project (e.g., `800x480`, `800x600`, `1024x768`, `1280x800`).
   - Every control's `X = xy1.x`, `Y = xy1.y`, `Width = xy2.x - xy1.x + 1`, `Height = xy2.y - xy1.y + 1`, and `ZIndex` (layer order from background rectangles -> images -> shapes -> outputs -> inputs -> buttons) are preserved to the pixel.
2. **Proportional Target Resolution Scaling Mode**:
   - When migrating an older panel resolution (e.g., `640x480` or `800x480`) to a modern widescreen panel (`1280x800` or `1920x1080`), scales `X` and `Width` by $S_x = W_{\text{target}} / W_{\text{source}}$, `Y` and `Height` by $S_y = H_{\text{target}} / H_{\text{source}}$, and scales `FontSize` by $\min(S_x, S_y)$ with optional aspect-ratio letterboxing.
